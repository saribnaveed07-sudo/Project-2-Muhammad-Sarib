# E-Commerce Store Wireframe: Landing Page and Checkout

## Description

This project is a low-fidelity UI/UX wireframe for an online store. It shows how a customer moves from the landing page to a purchase, covering the header, hero section, product listing, and checkout form.

The wireframe includes:

1. **Header:** A logo, a search bar, and a cart icon.
2. **Hero section:** A large banner image with a "Shop now" call to action.
3. **Products grid:** Six product cards in two rows, each with a name and price placeholder.
4. **Checkout panel:** Fields for shipping address, payment method, and contact number, a numeric keypad, and a "Place Order" button.
5. **Mobile screen:** A mobile version of the checkout flow.

The project focuses on how the layout guides users from browsing to placing an order, and on the checkout fields and controls needed to complete a purchase.
